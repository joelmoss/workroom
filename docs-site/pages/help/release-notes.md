Release notes are on [GitHub Releases](https://github.com/joelmoss/workroom/releases). Each release lists what changed.

## In the app

After an update, the app opens a What's New window the first time you launch it. It lists the release notes of every version from the one you had to the one you updated to, newest first, and each one has a **View on GitHub ↗** button. Choose **Done** to close it. It doesn't open on a fresh install.

## Stable and Nightly

Stable releases are the default and have a version number, such as v2.1.0. Nightly is a separate build of the latest work, which updates itself and runs next to your stable install. A change that is in Nightly but not yet in a stable release is marked with a Nightly badge in these docs.

See [Updates and channels](../app/updates-and-channels.md) for how to choose a channel and how updating works.
