# Synchronous file-system calls in Core/VersionControl, Core/AppShell and Core/Terminal that
# check-main-actor-fs.py lets through. Format: <file under WorkroomApp/Core> | <enclosing function> | <call> | <reason>.
# A new call belongs in GitRepositoryProbe.blockingRead/boundedRead, not here. Each reason starts
# with its kind:
#   off-main:      only ever runs off the main actor
#   known:         on the main actor, a documented exception
#   unbounded:     RepositoryLocation.local resolves on GCD (runBlocking), so the main actor never
#                  blocks, but the await has no timeout: GitRepositoryProbe.localLocation bounds it
#   grandfathered: on the main actor and undocumented; predates the Core/Terminal scan, unfixed
