# Codaset / Workroom logo assets

The square blocked symbol is the shared Codaset brand mark. The Workroom lockup pairs it with the Workroom wordmark.

## Files

- `codaset-symbol.svg` — yellow symbol on black; use as the default square logo.
- `codaset-symbol-yellow.svg` — yellow symbol on transparency; use on black or very dark backgrounds.
- `codaset-symbol-black.svg` — black symbol on transparency; use on yellow or very light backgrounds.
- `workroom-lockup-dark.svg` — yellow symbol and Workroom wordmark on black; default horizontal lockup.
- `workroom-lockup-yellow.svg` — yellow horizontal lockup on transparency.
- `workroom-lockup-black.svg` — black horizontal lockup on transparency.
- `codaset-lockup-dark.svg` — yellow symbol and Codaset wordmark on black; default parent-brand lockup.
- `codaset-lockup-yellow.svg` — yellow Codaset lockup on transparency.
- `codaset-lockup-black.svg` — black Codaset lockup on transparency.
- `workroom-by-codaset-lockup-dark.svg` — endorsed Workroom lockup with “by Codaset” beneath the wordmark, on black.
- `workroom-by-codaset-lockup-yellow.svg` — endorsed Workroom lockup in yellow on transparency.
- `workroom-by-codaset-lockup-black.svg` — endorsed Workroom lockup in black on transparency.
- `png/` — raster exports for contexts that cannot use SVG.

The lockup SVGs reference the bundled `assets/fonts/barlow-condensed-700.ttf` file. Keep the `brand/` and `fonts/` folders in their packaged relative positions when moving the editable assets. The PNG lockups have the wordmark rendered into the image and have no font dependency.

## Colour

- Signal yellow: `#FFEA00`
- Black: `#000000`

Keep the symbol square. Do not stretch, rotate, recolour, add shadows, or alter the spacing between its blocks.
