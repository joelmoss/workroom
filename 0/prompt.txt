2. Key Technical Concepts:
   - macOS SwiftUI app "Workroom" with a Go CLI engine and a Swift/Rust VCS layer; this session's focus is exclusively the `macapp/` Swift app.
   - `workroom-session` daemon: single-threaded `poll()`-based Unix-socket daemon (`SessionDaemon.swift`) that owns real PTYs (`SessionPTY.swift`) so shells survive app quit; client side is `SessionAttachClient.swift` (spawned as `workroom-session attach` inside a libghostty surface) and `PersistentSessionControlClient.swift`/`PersistentSessionService.swift` (app-side list/kill/info operations, separate lightweight one-shot client).
   - Wire protocol: `WorkroomSessionProtocol` module (`SessionFrame.swift`, `SessionMessages.swift`, `SessionReplayBuffer.swift`, `SessionWindowSizePolicy.swift`) shared between the app, the daemon, and the attach client.
   - `SessionWindowSizePolicy.isUsable`/`.attachSize`/`.createSize` — guards against garbage/transient pty sizes (ported/matching muxy-app/muxy's PR #1004 fix).
   - `SessionReplayBuffer` — ring buffer that deliberately drops content while the alternate screen is active ("full-screen programs get SIGWINCH instead").
   - tmux/screen-style "bump row count down then back up" trick to force a genuine PTY size delta and guarantee a full-screen program repaints on reattach (since a bare `SIGWINCH` with no actual size change can be silently ignored — observed: Claude Code ignores it, Codex doesn't).

   - `Defaults` (sindresorhus/Defaults-style property-wrapper library) for `backgroundSessions` (renamed to "Persist sessions" in UI) and other settings.
   - `TerminalPersistentSessionPolicy.usesPersistentSession(preferenceEnabled:isAvailable:isRunCommand:isQuickTerminal:isFixture:)` — the single policy gate deciding whether a tab gets a `persistentSessionID`.
   - `DispatchGroup`-based gating pattern for `applicationShouldTerminate`/SIGTERM handling — used repeatedly to make quitting wait for async cleanup (run commands, persistent-session kills, close-tab kills) before actually exiting, bounded by timeouts.
   - Unix domain socket trust model: `LOCAL_PEERCRED`/`peerUserID == getuid()` is the ONLY authentication — same-user processes can access each other's sockets (same threat model as tmux/screen); judged as an accepted, pre-existing architectural property, not a new regression.

     /// short-lived deadlines (poll timeouts, settle windows) where a `Date()`-based one could stall

     enum SessionClock {

         var descriptors = buildPollDescriptors()
         let ready = poll(&descriptors, nfds_t(descriptors.count), pollTimeout(isIdle: isIdle))

       let remainingMilliseconds = (nearest - SessionClock.monotonicSeconds()) * 1000
       return Int32(max(0, remainingMilliseconds.rounded(.up)))

         SessionPTY.resize(masterDescriptor: session.masterDescriptor, columns: pending.columns, rows: pending.rows)
         SessionPTY.requestRedraw(masterDescriptor: session.masterDescriptor, fallbackProcessID: session.processID)
       }
       return true
     }
