**[CRITICAL] (confidence: 8/10) `PersistentSessionService.swift:109-124`, `TerminalSessions.swift:1296-1304`, `AppStore.swift:3222-3224` — persistent-session teardown isn't awaited before the workroom's directory is deleted**


`reap()` fires this via an un-awaited `Task { await PersistentSessionService.shared.endSessions(matchingWorkroom: id) }` (TerminalSessions.swift:1304), and the caller proceeds synchronously:
```swift
// AppStore.swift:3222-3224
stopRunsAcrossWindows([targetID], stores: stores) { [weak self] in
```

`stopRunsAcrossWindows` deliberately blocks on a `DispatchGroup` so run-command dev servers exit before the worktree is deleted (comment cites issue #7: "the worktree must not be deleted while its dev server still holds the directory"). **[INFORMATIONAL] (confidence: 6/10) `PersistentSessionPaths.swift:56-65` — TOCTOU between the symlink check and the directory setup, chmod follows symlinks**

```swift
if fileManager.fileExists(atPath: url.path, isDirectory: &amp;isDirectory) {
  if (try? fileManager.destinationOfSymbolicLink(atPath: url.path)) != nil {
    throw PathError.directoryUnavailable
  }
  guard isDirectory.boolValue else { throw PathError.directoryUnavailable }
} else {
  try fileManager.createDirectory(at: url, withIntermediateDirectories: true)
}
try fileManager.setAttributes([.posixPermissions: 0o700], ofItemAtPath: url.path)
```
This only re-checks for a symlink in the "already exists" branch. In the `/tmp/workroom-&lt;uid&gt;` fallback path (world-writable dir, predictable name), if an attacker wins the race between the earlier `fileExists` (false) and this `createDirectory` call by planting a symlink to a directory the victim owns, `createDirectory(withIntermediateDirectories:true)` treats "EEXIST + stat-follows-to-a-directory" as success, and the subsequent `setAttributes(.posixPermissions:)` (which calls `chmod`, following symlinks) silently `chmod 0700`s whatever the symlink points at instead of failing closed. `liveSessions()` is a point-in-time snapshot; the actual attach happens later via `GhosttySurfaceView`/`SessionAttachClient`.
