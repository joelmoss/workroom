# Patches and exact line counts come from the owning host's git CLI, while history, refs and push state use gix

wr-agent reads history, ref decorations, push state and objects with gix in the `wr-vcs-git` crate, but the unified patch and the per-file line counts come from `git` on the owning host, run with the same comparison and repository config, so the app shows the numbers `git show` does. A spike's gix line counts matched git on only 139 of 150 commits, up to 4 lines off because of how `imara-diff` picks edit scripts, and gix writes no `diff --git` or rename headers. A "+N -M" badge that disagrees with git is a product bug, so approximate counts and patches synthesised in wr-agent were rejected. gix was preferred over `git2-rs` because it is pure Rust, where `git2-rs` would add the C-linking `libgit2-sys` and `openssl-sys`. The crate is separate because `wr-vcs-model` forbids gix by a written invariant. Local reads on the Mac use libgit2 (see ADR 0002).
