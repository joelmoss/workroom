# Local git reads call libgit2's C API, only inside the `WorkroomGit` package, on a vendored libgit2

Local reads run in Swift straight on libgit2's C API. `GitRepository` holds the reads `GitProvider` maps into the app's models (history, HEAD and branches, tags, working-tree status, blobs, single-file patches), as Swift values that never carry a libgit2 pointer out of the read that opened the repository; `GitGraph` (push state over a commit range), `GitCommitDiff` (rename detection on commit diffs) and `GitDiffStats` (working-tree line counts) are readers of their own; `LibGit2` owns the one `git_libgit2_init` and the diagnostics. Only `macapp/Packages/WorkroomGit` imports `libgit2`: `git grep -l '^import libgit2' -- 'macapp/*.swift'` names that package's sources and the `LibGit2` package's own tests, nothing else. libgit2 itself is the release that `macapp/Scripts/vendor-libgit2.sh` vendors into `macapp/Packages/LibGit2` (its `VENDOR.md` names it), built for macOS with every network transport off, since fetch, push and pull run the git CLI (ADR 0003). An all-Rust core on gix was tried and dropped: it bought no real unification, and libgit2 is the more complete engine.

History: until 2026-11-26 the reads went through SwiftGitX, and libgit2 came from SwiftGitX's own fork, pinned at the same URL and version so SwiftPM saw one package. That fork's "1.9.2" was a June 2025 snapshot of libgit2's main branch reporting 1.9.0, so it carried none of upstream's v1.9.1–v1.9.7 fixes, among them the 2026 security releases and support for `extensions.relativeWorktrees`, without which libgit2 cannot open a repository that has a relative-path worktree at all. Neither SwiftGitX nor the fork had released since December 2025, and SwiftGitX pinned the fork exactly, so no fix could arrive without both. The raw C API had already been needed in four files for what SwiftGitX could not express (no `git_revwalk_hide`, an internal repository pointer, a `git_diff` freed before returning, eager hunk lines); `GitProvider` used about a dozen of its calls besides.
