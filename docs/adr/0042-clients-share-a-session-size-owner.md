# Several clients attach to one session and see the same output, and only the pty size has an owner

A `wr-agent` session takes any number of attached clients, and each receives the same output bytes. Nothing is superseded. The retired Swift daemon let a new client replace the earlier one, and a review of #181 proposed the same, but several clients on one session is the point of remote workrooms and of reattaching from a second Mac. The one thing arbitrated is who owns the pty size, because two clients will not agree on a window size and last write wins would make it thrash. A client takes the size from the client that owns it only by acting, with a keystroke or a click, never by attaching, resizing or having its terminal answer a query. With no owner, an attaching or resizing client takes the vacancy, and the last client left takes it when the others detach. Telling those apart takes a stateful parser, because focus reports, cursor position and device attribute answers, colour and clipboard replies, kitty keyboard flag reports and wheel scroll arrive on the same channel as typing, and a report split across two frames must not read as a keystroke. A non-owner's resize applies only once it claims.
