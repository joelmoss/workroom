# The Mac authenticates to the broker with a device key, hardware-bound where there is a Secure Enclave, not a bearer token

Each Mac signs every broker request with a P-256 key, as a DPoP-shaped ES256 proof, so a stolen bearer token cannot be replayed as this Mac. The key lives in the Secure Enclave where there is one, and there it cannot be exported; its blob sits in the Keychain tied to the code signature. Intel Macs get a software key instead, kept in the login Keychain tied to the code signature but exportable, and it can migrate to another Mac with the Keychain, so the hardware guarantee holds only on Macs with a Secure Enclave. Device keys are registered at the broker, so a change of key scheme would mean signing every Mac in again.
