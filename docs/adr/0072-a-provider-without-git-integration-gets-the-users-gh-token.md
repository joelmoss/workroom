# A remote provider with no git integration gets the user's `gh` token on its host, refreshed on every connect

Proposed 2026-11-13, from the Railway sandboxes design interview; amends [ADR 0049](0049-provider-hosts-bring-their-own-git-credentials.md). It is accepted once the live spike shows a Railway host cloning and pushing in the user's name with it.

ADR 0049 has a provider's host fetch and push with the provider's own GitHub credentials, because pushes must be in the user's name and broad repository scope inside the host is acceptable. Railway documents no git integration for sandboxes, and the credential relay of [ADR 0039](0039-container-workrooms-ride-the-remote-path.md) answers only while the Mac is connected, while a remote workroom's coding agents keep pushing with the Mac asleep. So a Railway host gets the Mac's `gh auth token`: at create Workroom writes it to a file on the host readable only by its owner, sets a git credential helper that answers from it for `https://github.com`, and the same `insteadOf` rewrites from every GitHub remote form to https that the exe.dev driver sets. On every connect the app compares it with the Mac's current token and rewrites it when they differ, so a token the user rotated or revoked does not live on in a host. Clearing a checkpoint of its checkout (`CheckoutClearingDriver`) removes the file too. Deleting the workroom destroys the sandbox and the file with it. The scope is the user's `gh` scope, the blast radius ADR 0049 already accepted for boxd, and anything in the workroom can read it, as with the relay.

Rejected: the token as a Railway sandbox variable (`--variable GH_TOKEN=...`, the only recipe Railway's docs give). It sits in Railway's variable store for the sandbox's life and is not carried to a fork or a checkpoint's restore. Rejected: the credential relay. Pushes would fail whenever the Mac sleeps. Rejected: a broker minting per-repository tokens (ADR 0024, superseded). Pushes would come from an App's bot, not the user.

Source: [`docs/designs/railway-sandboxes-research.md`](../designs/railway-sandboxes-research.md) (section 4).
