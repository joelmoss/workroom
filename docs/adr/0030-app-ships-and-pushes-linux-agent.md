# Workroom.app ships the Linux wr-agent and pushes it when a host has none or an older one, and the Go CLI stays on the Mac

No provider image carries wr-agent. The app bundles a static musl wr-agent for both Linux architectures in `Contents/Resources`, in every build whatever `ARCHS` says, and `AgentBootstrap.connect` pushes it through `HostDriver.exec` on first connect, beside the socket in its 0700 directory. The install stages the file, checks its digest, runs `protocol`, offers a hand-off (ADR 0009) and renames it into place only if nothing refused it, because relay, attach and the supervisor execute the on-disk file. A host that runs a newer build is never downgraded: builds are ordered by a number taken from the commit time. This gives one source of truth with no image maintenance, and it works for providers that have no image concept. The cost is two ELFs in the app and a refused install being pushed again on the next connect. Clone, fetch and checkout run through wr-agent's exec service, so no Linux Go binary is pushed and no second config appears on a host.
