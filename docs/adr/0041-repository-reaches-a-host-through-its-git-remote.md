# The repository reaches a host only through its git remote, and only from GitHub.com

A remote workroom's repository is cloned on the host from the project's GitHub origin, and the workroom's own branch is then checked out. The local working copy is never synced, and unpushed local work is not carried over, so work in progress on the Mac does not appear on the host until it is pushed. Every remote workroom is a fresh host (see ADR 0017), so there is no shared `.git` to make a worktree from, and syncing the working copy was rejected. Remote workrooms require a github.com origin, because the broker mints tokens for github.com only (see ADR 0024), and a project whose origin is elsewhere is refused. Non-GitHub remotes stay an open question in the design (OQ6): a plain git-over-ssh remote has no answer for credentials.
