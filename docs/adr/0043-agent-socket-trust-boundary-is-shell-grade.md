# The wr-agent socket's 0700 directory is the only trust boundary, so exec and hand-off are shell-grade

Decided 2026-09-25 by the owner. A client of the `wr-agent` socket may type into every session, run `git` with arbitrary argv, and name any regular file for hand-off to `execve`. That is accepted because the socket sits in a user-owned 0700 directory, and anything that can reach it could already start a shell, so these capabilities cross no user boundary the socket does not already cross. What hand-off adds is persistence: a same-user process could make `wr-agent` become its own binary and keep every terminal. The `Executable` enum is not containment, because `git` with arbitrary argv is arbitrary code execution, and validating argv cannot be made safe. A path allowlist is deferred. So any transport that carries exec must authenticate its peer to shell grade, not repository grade, and the File service stays separate and narrower, with no client argv, so a transport can authenticate it differently. `wr-agent` does not check the directory's mode itself. The host setup makes the directory the user's own and 0700.
