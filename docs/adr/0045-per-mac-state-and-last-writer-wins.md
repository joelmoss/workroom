# Focus and frames stay per Mac, and a workroom's host layout syncs as a whole snapshot, last writer wins

Focus, popped-out frames, windows and the revision and stale mark a Mac keeps stay in its own `session.json`, because two viewers share no cursor or screen geometry. The app strips them from the host blob and puts focus and frames back by what a tab shows, since tab keys are re-minted on every restore; a permanent pane key was rejected. Sync is on open and write through on change: a refused write sends this Mac's whole snapshot again at the current revision, at most three attempts. There is no live mirroring, journal or merge, because the app saves whole debounced snapshots with no single change to replay. A write that does not reach the host marks the copy stale, and a stale copy wins at the next open. At open a remote workroom waits up to 5 seconds for its host's layout, restores the host's layout when its revision differs from the one this Mac last saw, this Mac's own copy if that copy never reached the host (stale) or the host is silent, and never overwrites a layout it did not read. Another Mac's tab order and its diff, file and changeset tabs can be silently overwritten.
