# Release and Nightly share boxd and exe.dev hosts, and each build owns its own container hosts

Every host descriptor records its `provisioner`, the bundle id of the build that made it. A container host takes its build's ssh key and Docker labels, so only the build that made it adopts, sweeps or opens it, and one build's sweep cannot remove another's containers. Hosts on boxd and exe.dev are different: they are reached through the provider's CLI and a key the provider or the user owns (boxd's CLI key, the user's own ssh on exe.dev), and a grant cancels by Codaset user, so nothing on them belongs to a build. Release and Nightly, which share one config (they are separate products, see ADR 0015), therefore open and delete each other's provider hosts. A Dev build keeps its own config and hosts. The consequence is that a host holds the newest wr-agent either build pushed, so the two builds must stay compatible (see ADR 0037).
